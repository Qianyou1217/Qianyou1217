# QIANYOU HUANG

## About Me

Hi, I'm Qianyou Huang, a composer and arranger. I can speak both Chinese (正體中文) and English. 

Right now, I'm working on a piece called *The Puppet Answered By Anemo* (Fan-made Theme for Wanderer).

My Favorite composer is Maurice Ravel, and my favorite piece are *Le Tombeau de Couperin*, *Piano Trio in A minor*, *Menuet sur le nom d'Haydn* and some other piece from Ravel. I also like music from HOYO-MiX, Like *O Strings, My Strings* and *I Loved You*.
